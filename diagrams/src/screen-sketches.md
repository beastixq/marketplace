# Черновые эскизы экранов

Эти схемы показывают распределение действий по будущим экранам. Это редактируемые наброски, а не утверждённый UI-дизайн. Надписи в квадратных скобках обозначают элементы управления.

## 1. Каталог — гость и покупатель (F-1)

```text
┌────────────────────────────────────────────────────────┐
│ Маркетплейс       [Поиск товара    ] [Войти] [Корзина] │
├─────────────────┬──────────────────────────────────────┤
│ Категории       │ [Сортировка] [Фильтры]               │
│ [Электроника]   │ ┌─────────┐  ┌─────────┐  ┌─────────┐│
│ [Одежда]        │ │ Товар   │  │ Товар   │  │ Товар   ││
│ ...             │ │ цена    │  │ цена    │  │ цена    ││
│                 │ │[Открыть]│  │[Открыть]│  │[Открыть]││
│                 │ └─────────┘  └─────────┘  └─────────┘│
│                 │ [Предыдущая]  1 / N  [Следующая]     │
└─────────────────┴──────────────────────────────────────┘
```

Выбор товара открывает карточку; поиск, категория и страницы меняют список.

## 2. Карточка товара и отзыв (F-1, F-2, F-6)

```text
┌─────────────────────────────────────────────────────────────┐
│ Каталог / Категория / Товар                       [Корзина] │
├────────────────────────────┬────────────────────────────────┤
│ Название, продавец         │ Цена, доступное количество     │
│ Описание, категории        │ [Количество] [В корзину]       │
│ История цены [Период]      │ Ошибка: товара недостаточно    │
├────────────────────────────┴────────────────────────────────┤
│ Рейтинг и отзывы  [Следующая страница]                      │
│ После доставки своего заказа: [Оценка] [Текст] [Отправить]  │
│ Если отзыв уже есть:       [Изменить] [Удалить]             │
└─────────────────────────────────────────────────────────────┘
```

Форма нового отзыва доступна покупателю только после `delivered`; повторный отзыв заменяется редактированием существующего.

## 3. Корзина и оформление (F-2, F-3)

```text
┌────────────────────────────────────────────────────────────┐
│ Корзина                                                    │
├────────────────────────────────────────────────────────────┤
│ Товар A        2 × цена     [Количество] [Удалить]         │
│ Товар B        1 × цена     [Количество] [Удалить]         │
│ Итого по корзине                                  Сумма    │
├────────────────────────────────────────────────────────────┤
│ Адрес доставки [Сохранённый адрес         ▼] [Новый адрес] │
│ [Оформить заказ]                                           │
│ Ошибка: недостаточно товара / нет адреса; корзина сохранена│
└────────────────────────────────────────────────────────────┘
```

Одно действие оформления создаёт один `pending`-заказ на каждого продавца; ошибка не оформляет часть корзины.

## 4. Заказы и оплата (F-3, F-4)

```text
┌────────────────────────────────────────────────────────────┐
│ Мои заказы               [Текущие] [Завершённые]           │
├────────────────────────────────────────────────────────────┤
│ Заказ #1 · продавец A · pending · сумма   [Оплатить]       │
│                                            [Отменить]      │
│ Заказ #2 · продавец B · pending · сумма   [Оплатить]       │
│                                            [Отменить]      │
│ [Открыть заказ] → товары, адрес и текущий статус           │
│ У оплаченного/отправленного/доставленного заказа: статус   │
└────────────────────────────────────────────────────────────┘
```

После оформления покупатель видит отдельные заказы и оплачивает каждый отдельно через учебный Mock Bank. Отмена доступна до `shipped`.

## 5. Кабинет продавца (F-4, F-5)

```text
┌────────────────────────────────────────────────────────────┐
│ Продавец      [Товары] [Заказы] [Статистика]               │
├────────────────────────────────────────────────────────────┤
│ [Добавить товар]   Товар · цена · остаток [Править]        │
│ Форма: название, описание, цена, остаток, категории [Save] │
│ Заказы: paid [Отправить] → shipped [Доставлен]             │
│ Статистика: [С даты] [По дату] [Показать]                  │
│ Заказы / выручка / средний чек / лидер продаж              │
└────────────────────────────────────────────────────────────┘
```

Продавец управляет только своими товарами и заказами.

## 6. Администратор и аналитик (F-5)

```text
┌────────────────────────────────────────────────────────────┐
│ Администратор: [Пользователи] [Категории] [Заказы]         │
│ Пользователь · роль · состояние          [Изменить]        │
│ Категория · родительская категория       [Создать/Править] │
├────────────────────────────────────────────────────────────┤
│ Аналитик: [Период] [Сформировать отчёт]                    │
│ Общие показатели / динамика заказов / лидеры продаж        │
└────────────────────────────────────────────────────────────┘
```

Это два отдельных набора доступов; аналитик просматривает данные без изменения.
