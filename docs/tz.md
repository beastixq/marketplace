# Техническое задание

```
Тема:
Разработка базы данных онлайн-маркетплейса

Аналитический раздел:
Провести анализ предметной области онлайн-маркетплейса и существующих
аналогов (Ozon, Wildberries); сформулировать требования и ограничения к
разрабатываемой базе данных и приложению для управления товарами,
заказами и пользователями маркетплейса.

Конструкторский раздел:
Спроектировать сущности базы данных онлайн-маркетплейса с ограничениями
целостности и ролевой моделью доступа (покупатель, продавец, администратор,
аналитик); спроектировать триггер аудита изменений цен на товары и
хранимую функцию расчёта статистики продаж продавца.

Технологический раздел:
Выбрать средства реализации базы данных (PostgreSQL) и приложения (язык Go);
разработать сущности базы данных с ограничениями целостности и внешним
кэшированием на Redis; описать интерфейс доступа к базе данных через REST API.

Исследовательский раздел:
Провести исследование зависимости времени выполнения запросов к базе данных
от наличия и типа индексов методом EXPLAIN ANALYZE; исследовать влияние
Redis-кэширования на время отклика приложения при нагрузочном тестировании.
```

Структура РПЗ и исследовательский раздел — см. [RPZ.md](RPZ.md).
