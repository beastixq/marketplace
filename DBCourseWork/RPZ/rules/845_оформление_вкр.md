# Памятка 845: оформление РПЗ

Источник: `DBCourseWork/845_Pamyatka po oformleniyu VKR dlya studentov MGTU-2022.pdf`.

Пользователь задал этому документу больший приоритет по сравнению с общими ГОСТами. При конфликте с методичкой кафедры сначала проверять методичку и ТЗ, затем памятку 845.

## Проверка в системе

- Предварительная проверка проверяет структуру РПЗ, наличие титульного листа, соответствие фамилии студента, наличие всех разделов, правильность заголовков и оформление текста.
- Окончательная проверка отсекает титульный лист и список использованных источников, затем проверяет объем заимствованного текста.
- Допустимый объем заимствования по памятке: не более 40%.
- Наличие титульного листа при загрузке обязательно.
- Электронный вариант РПЗ должен быть одним файлом с обязательным титульным листом и другими структурными элементами.

## Общие требования к файлу

- Для Word указан формат `.docx` и размер до 20 МБ. Для LaTeX-проекта проверять итоговый PDF как один файл.
- Текст РПЗ должен быть единым, без внедрения других документов как отдельных редактируемых объектов.
- Надписи, таблицы и рисунки должны быть встроены в текст и не выходить за его рамки.
- Рисунки должны содержать небольшое количество текстовой информации.
- Текст в надписях не должен выходить за границы.
- Формулы и обозначения должны быть набраны как формулы, а не обычным текстом.

## Шрифт и цвет

- Основной шрифт: Times New Roman, 14 пунктов.
- Фрагменты кода программ: Courier New.
- Цвет шрифта: черный.
- Цветными могут быть только рисунки, фотографии и схемы.
- Допускается акцентирование терминов, формул и теорем полужирным, курсивом или подчеркиванием.

Проверочная трактовка для LaTeX:

- основной текст должен визуально соответствовать Times New Roman 14 pt;
- листинги кода должны быть моноширинными;
- цветной текст в основном содержании не допускается.

## Переносы

- Должна быть автоматическая расстановка переносов.
- Принудительная расстановка переносов не допускается.
- Переносы слов в заголовках не допускаются.

## Поля и интервалы

- Левое поле: 3 см.
- Правое поле: 1 см.
- Верхнее поле: 2 см.
- Нижнее поле: 2 см.
- Выравнивание текста: по ширине.
- Отступ первой строки абзаца: 1,25 см.
- Междустрочный интервал: 1,5 строки.
- Не должно быть лишних ручных отступов и интервалов.

## Колонтитулы и нумерация

- Титульный лист считается первым.
- Номер на титульном листе не ставится.
- Со следующего листа нумерация ставится в нижнем колонтитуле по центру.
- Номер должен быть симметричен тексту.
- Нижний колонтитул должен содержать один абзац.
- Размеры колонтитулов: 1,25 см.
- Верхний колонтитул пустой.

Проверочная трактовка для текущей РПЗ:

- если ТЗ вставлено как официальный бланк, не печатать поверх него номер средствами LaTeX;
- счетчик страниц должен учитывать титул и задание;
- первый обычный лист после титула и задания обычно получает номер 3;
- если нормоконтролер требует строгое правило 845, лист после титула должен иметь напечатанный номер 2. Это надо отметить как вопрос для руководителя.

## Структурные заголовки

Структурные элементы РПЗ не нумеруются, располагаются по центру, пишутся прописными буквами и без точки в конце:

- `РЕФЕРАТ`;
- `СОДЕРЖАНИЕ`;
- `ОПРЕДЕЛЕНИЯ`;
- `ОБОЗНАЧЕНИЯ И СОКРАЩЕНИЯ`;
- `ВВЕДЕНИЕ`;
- `ЗАКЛЮЧЕНИЕ`;
- `СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ`;
- `ПРИЛОЖЕНИЯ`.

Дополнительные правила:

- для структурных заголовков допускается шрифт 15-16 пунктов, полужирный;
- каждый структурный элемент начинается с новой страницы;
- после номера раздела, подраздела, пункта и подпункта точка не ставится;
- в конце заголовка точка не ставится;
- если заголовок состоит из нескольких предложений, каждое предложение заканчивается точкой, кроме последнего;
- заголовок `СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ` обязателен;
- заголовок `ПРИЛОЖЕНИЯ` должен быть упомянут в содержании даже при одном приложении.

## Таблицы

- На все таблицы должны быть ссылки в тексте.
- Таблица располагается сразу после абзаца с первой ссылкой на нее или на следующей странице.
- Таблица выравнивается по центру относительно текста.
- Номер и название таблицы указываются над таблицей отдельным абзацем.
- По памятке 845 номер и название начинаются от правого края таблицы. Если это конфликтует с ГОСТ 7.32 из методички, приоритет для оформления имеет 845.

## Рисунки

- На все рисунки должны быть ссылки в тексте.
- Рисунки выравниваются по центру относительно текста.
- Номер и название рисунка указываются под иллюстрацией отдельным абзацем.
- Подпись рисунка должна быть без отступа первой строки.
- Рисунки не должны выходить за поля.
- Текст внутри рисунков должен быть читаемым.

## Формулы

- Формулы выделяются отдельной строкой.
- Выше и ниже формулы оставляется одна пустая строка.
- Расшифровка символов приводится непосредственно под формулой в той же последовательности.
- Первая строка пояснения начинается со слова `где` без двоеточия.
- Каждое пояснение, кроме первого, начинается с новой строки.
- Формулы нумеруются в пределах всего текста арабскими цифрами в круглых скобках.
- Номер формулы выравнивается по правому краю, сама формула — по центру.
