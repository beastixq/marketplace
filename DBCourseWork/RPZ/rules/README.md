# Правила проверки РПЗ

Эта папка содержит сжатые проверочные правила, извлеченные из локальных PDF в `DBCourseWork/`.
Правила нужны для аудита РПЗ по исходникам LaTeX и итоговому PDF.

## Источники

- `../../На что обратить внимание в РПЗ.pdf`;
- `../../845_Pamyatka po oformleniyu VKR dlya studentov MGTU-2022.pdf`;
- `../../Реферат_требования.pdf` — ГОСТ 7.9-95;

- `../../764_Polozhenie o normokontrole, razmeschenii VKR v EBS i proverke na obem zaimstvovaniya.pdf`.

## Приоритеты

При конфликте требований применять порядок:

1. ТЗ текущей курсовой и прямые требования руководителя.
2. Методические указания кафедры по курсовой работе.
3. Памятка 845 МГТУ по оформлению РПЗ, поскольку пользователь задал ей больший приоритет над общими ГОСТами.
4. ГОСТ 7.9-95 для реферата.
5. ГОСТ 7.1-2003 для списка использованных источников.
6. Положение 764 по нормоконтролю и проверке заимствований.
7. Локальные текстовые правила проекта из `DBCourseWork/AGENTS.md`.

Если правило из ГОСТа противоречит памятке 845, для этой курсовой применять памятку 845 и отметить конфликт в аудите.

## Как применять

- Проверять PDF: порядок листов, наличие титула и задания, печатные номера страниц, поля, вид заголовков, подписи таблиц и рисунков.
- Проверять LaTeX: порядок `\include`, `\includepdf`, `\setcounter`, подписи/метки, наличие ссылок на таблицы, рисунки и приложения.
- Проверять текст: соответствие разделов методичке, отсутствие терминов реализации раньше нужного раздела, отсутствие воды и неподтвержденных утверждений.
- Проверять список источников отдельно по `Библиографическая запись.md`.

## Спорные правила для текущей РПЗ

- Титульный лист входит в общую нумерацию, но номер на нем не печатается.
- Задание вшивается в РПЗ по методичке. Если оно вставляется как официальный бланк, не печатать поверх него номер страницы; при этом лист учитывается в счетчике. Следующий лист после титула и задания обычно получает номер 3. Это практическая трактовка, ее стоит подтвердить у руководителя или нормоконтролера.
- Приложения являются структурным элементом РПЗ, оформляются как продолжение записки и имеют общую сквозную нумерацию страниц. Поэтому в реферате число страниц следует считать по всему PDF РПЗ, включая приложения, если отдельное кафедральное требование не говорит считать только основной текст.
